docs: p11c held-out 实测落地（acc 无可检出提升，且实验按设计看不见 +3pp）

数据源: python -m rlab.eval --algo retool_math --no-difficulty_filter
  BASE = sft_budget_v3/epoch1（RL 起点）, N=293 greedy seed 42

四臂实测:
  BASE    79.2 / 93.5 / 条件 84.7 / 2512tok / 1.85轮
  step100 80.2 / 91.8 / 条件 87.4 / 2740 / 1.86   +1.0pp p=0.736
  step200 76.5 / 93.2 / 条件 82.1 / 2571 / 1.59   -2.7pp p=0.272
  step300 77.8 / 92.2 / 条件 84.4 / 2598 / 1.47   -1.4pp p=0.590
  step400 81.2 / 91.1 / 条件 89.1 / 2642 / 1.65   +2.0pp p=0.533

三条结论:
1. acc 全落在噪声内，但这不是"RL 无效"的证据 —— 是功效不够。
   N=293 的 MDE(80%功效)=6.3pp, @50%=4.4pp; 目标效应 +3pp 不到门槛一半。
   同一个盲点已报销两轮: p9 真实效应 +3.8pp 也是 p=0.161。
   要测 +3pp 需 N≈1306, dev 只有 1000 => 现有池子上限 MDE=3.4pp。

2. 条件精度首次移动 84.7%->89.1%(+4.4pp), fmt -2.4pp, acc 两段自洽。
   但这既不是"涨了"也不是"噪声" —— 正是 AGENTS.md 记的 v3 事故的镜像形态
   (两个不显著的 Δ 之商), 判"格式换推理"必须对 acc 做同题配对, N=293 做不了。

3. 行为确实变了且可测: 工具轮数 1.85->1.47(泊松 z=3.57, p<0.001),
   同时每轮 token 1358->1770(+30%)。模型学会"少调用、每次写更长"。
   但它与 fmt -2.4pp 同向: 调用轮少 => 收尾机会少 => no-boxed 变多。
   效率项在起作用, 代价打在交卷率上 —— 这是比 acc 是否显著更有信息量的机制发现。

剂量视角(p11d §9.1): SFT 268 updates @1e-5, p9 RL 50, p11c 42 @1e-6
  => RL 累计参数位移只有 SFT 的 1.6%。lr 5e-6 已被 p3 实锤学崩,
  唯一安全的加剂量途径是增加 updates 数: GAS 8->2 零额外 token 换 4x updates。
